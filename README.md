# ConnectHub

ConnectHub is a full-stack social media platform.

## Features

- Create posts
- Like posts
- Comment on posts
- Share posts
- User profile
- Social media news feed

## Technologies Used

- React
- JavaScript
- Vite
- CSS
- Node.js
- Express.js
- MongoDB Atlas

## Project Structure

5fj/
- frontend/
- backend/

## How to Run

### Backend

Open a terminal and run:

cd backend

npm install

node server.js

Backend runs at:

http://localhost:5000

### Frontend

Open another terminal and run:

cd frontend

npm install

npm run dev

Frontend runs at:

http://localhost:5173

Open the frontend URL in your browser to use ConnectHub.
